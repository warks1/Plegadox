# Plegadox

Software nuevo de programación y simulación de plegado, basado en el flujo del Cybelec 15T y configurado inicialmente para Trumpf V85.

Este repositorio se inicia desde cero, sin archivos heredados de Plegar Pro Plus.

> Estado: desarrollo. Los cálculos preliminares no son una validación de seguridad para operaciones reales.
